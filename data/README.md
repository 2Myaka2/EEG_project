# Data

This project uses the EEG During Mental Arithmetic Tasks dataset from PhysioNet.

Dataset page:
https://physionet.org/content/eegmat/1.0.0/

Raw EDF files are not stored in this repository.

To reproduce the project:
1. Download the dataset archive from PhysioNet.
2. Extract it into `data/raw/`.
3. Keep the original file structure.

Expected files:
- `Subject00_1.edf` — background EEG
- `Subject00_2.edf` — EEG during mental arithmetic task
- ...
- `subject-info.csv`
